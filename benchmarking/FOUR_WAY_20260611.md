# Four-way benchmark — canonical numbers (2026-06-11 epoch)

Final re-baseline after the provenance-consolidation plan
(`docs/provenance-consolidation-plan.md`, Steps 0–4 complete at commit
`a240525`). All four sweeps ran in one epoch with the same toolchains
(`~/.nargo/bin/nargo`, `~/.bb/bb`, same Zinnia build), repeats = 3.
Per the versioning rule, never compare these gates/cells against numbers
produced by a different bb build or a pre-Step-0c compiler — the ~20
correctness fixes invalidated all earlier baselines (several "fast" old
numbers were witness-specialized mis-compiles).

## Distribution notes

- Noir gates: only 2 of 126 cases above 1.5× — 0450 (2.39×,
  triple-fancy-index gather) and 0490 (1.58×, np.where scatter loop).
  Next worst: 0508 at 1.39× (bbox crop; Zinnia's contract binds the
  top-left-packed crop, a ~900-mul 2-D gather floor the in-place-masked
  handwritten circuit doesn't pay).
- halo2 time: worst case 1.25× (0343); minimum-k histogram (ZN−HW):
  ZN needs a smaller or equal k in 101/124 cases (e.g. 0416/0418 k=10
  vs HW k=11 after the BlockView reshape lowering, advice cells
  258,157 → ~8,000).

## Reproduction

```bash
cd benchmarking   # ZINNIA_RELEASE_BUILD_READY=1 if the extension is fresh

python run_zinnia_noir.py     --cases all --repeats 3 --per-case-timeout 300 --out zn_noir.json
python run_halo2_baselines.py --repeats 3 --out hw_halo2.json

```
