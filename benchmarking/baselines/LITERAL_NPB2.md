# Literal npb2 baselines

Original fixture shapes; 2026-10-09. All 20 cases have both literal source files. The earlier 17 tracked draft/committed files and the existing untracked softmax Noir draft were reviewed and reused; the per-case notes identify repairs. Computations were derived from kernel.py, with L1-L6 checked statement by statement. No optimized files, gadgets, fixtures, case sets, or checking tools were changed.

**Outcome:** 12 cases pass both checkers; seven have only the halo2 redundant-input-check conflict; periodic distance passes halo2 but Noir exceeds 8 GiB. All 20 optimized checks pass. Strict same-domain comparison remains unresolved for complex clip, Fibonacci, periodic distance, sumarray3d and weighted distance for the reasons below; those comparisons are excluded from any certified fair aggregate.

Validation uses only `hw_check.check --no-prove`: halo2 A/B MockProver runs, cells, and one out-of-domain input rejection; Noir compilation, unpadded UltraHonk gates, A/B witness solving, and one out-of-domain rejection. No keys, proofs, public-tamper proof checks, timings, scaling runs, Zinnia runs, IR, emitted code, or Zinnia sizes were used. Fixture agreement is not a proof of all-input semantic equivalence.

Commands ran from `benchmarking/baselines` with `../../.venv/bin/python`, `HW_VARIANT=literal`, `CARGO_TARGET_DIR=target-literal`, `--profile dev-fast`, `CARGO_BUILD_JOBS=3`, and the supplied `lock-b`. All heavy commands used memrun with `MEMRUN_MAX=8G`; temporary packages/logs stayed under the batch work directory. ## Interpretations and audit caveats

- **clip / comparisons:** integer `np.clip` is pairwise maximum followed by minimum, not the region-hinted `clip_const`. Fresh bounds are used at every comparison, including array elements and constants (constants use bounded constants). Only cell values survive between operations; I64/window proofs are not cached.
- **Reductions:** `@`/`np.dot` use the shared one-rescale dot algorithm; empty dots are constant zero followed by the written subtraction. All explicit Python loop products and elementwise powers round before addition. NumPy sums/cumsum use running accumulators in index order. View, reshape, broadcast and tile movement uses wires; every arithmetic intermediate array is fully computed.
- **Division / roots:** ordinary division uses the general shared division gadget, with a fresh divisor bound in halo2. Constants may be folded per L3. No independent guessed witnesses or hinted-result verification gadgets were introduced; Fibonacci’s final range check is a statement-domain check, described below. The shared sqrt has its own floor-root constraints.
- **Square-root domain conflict requiring author review:** optimized wdist, sumarray3d, periodic_dist and complex clip contain extra backend radicand guards (signed64 on halo2, in some Noir cases unsigned64), beyond the shared sqrt gadget. The literal files call shared sqrt directly, following the brief’s prohibition on extra range checks the shared gadgets would not do. Consequently the table does not certify equal acceptance domains for those comparisons; exclude them from a strict fair aggregate until this rule/contract conflict is resolved. Their fixture checks alone do not settle it. No optimized file or gadget was changed.
- **Softmax:** use the shared canonical exp family already selected by the optimized baseline, evaluated on the literal `x - tmp_max`; no alternate minimax approximation, specialized negative-gap rewrite, or max hint. Full maxima, subtraction, exp, sums, divisions are distinct passes.
- **Complex clip:** use the optimized case’s Q32 primitive arithmetic (round real/imaginary component squares before sqrt; round complex/real division numerator `component * magnitude` and denominator `magnitude * magnitude`). This overrides the older raw-hypot permission in NPB_BASELINES. Each of the three source abs occurrences is recomputed. Both branches compute; zero division is totalized only on inactive branches, with a guarded assertion forbidding active zero division. No abs result is shared across source expressions.
- **Fibonacci:** preserve 1024 iterations from @requires and select both state variables; do not shrink the circuit to n<=90 or use matrix powers. A final int64 output check implements NPB_BASELINES section 5.7. Host enumeration of all n=0..1024 confirms no modular field-wrap result outside n<=90 can pass that check. The optimized file lacks this final check and explicitly describes larger n as field arithmetic, so its all-input statement is not certified equivalent.
- **Insertion sort:** bound while by i; preserve private j and its selected decrement. Independently index the condition and body RHS; each write scans equality tests over every slot. The inactive j=0 condition/body evaluates index -1, a valid NumPy index, and the j>0/active flag suppresses effects. No static j=i-step substitution, early insertion, sorted hint or sorting network.
- **Periodic distance:** Python evaluates the RHS before the assignment target. Each repeated mask is computed separately; the RHS uses L5 running-count/equality-test compaction, the LHS scatters by independently recomputed counts. Internal dynamic lengths use fixed-capacity padding, not additional public outputs. Padding arithmetic has no effect on selected values. Both complete branch arrays are computed then selected by the runtime periodic flag. The final scalar masked assignment is a per-element select.
- **Hdiff / input liveness:** L2 requires all lap_field entries, including the corner intermediates the optimized lazy stencil omits. Their required input elements are loaded/domain-checked once; only the four input-array corners never read by the source are omitted. This follows the literal full-array rule over optimized dead-intermediate omission. The overwritten out_field parameter remains unused.
- **D2Q9:** retain helper calls and periodic loops rather than replacing them with wrap indexing. Unread overwritten boundary values are placeholders under L7 until copies assign them. All source float-constant products use mul, including repeated occurrences; the source integer -2 product is exact mixed integer multiplication. NS/MS are fixture shape constants; explicit population indices 0..8 remain source literals. setf retains its transposed indices.
- **Matrix multiply:** preserve zero(n,m) as m rows of n; the fixture has N=P, as required by the source’s later indexing. The helper is called where the source calls it. Sumarray3d likewise keeps its nested helper and scalar assignment order.
- **Lint warnings:** D2Q9 population indices/coefficient denominators are kernel-text constants, not dimensions; sumarray3d’s 3 coordinates and lapl3d’s multiplier 4 / Q32 epsilon 4 are also text/number-format constants. They are not shape-specialization shortcuts. Final `hw_check.lint` reports zero errors (`lint-final.log`).
