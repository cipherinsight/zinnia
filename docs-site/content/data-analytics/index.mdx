# Data Analytics Overview

Zinnia compiles Python functions that use NumPy into zk-SNARK circuits over the BN254 scalar
field. A data analyst can publish the result of a computation together with a proof that the
result was computed correctly from inputs that stay private. This section describes the parts
of the language that matter for such workloads: arrays, real-valued arithmetic and non-linear
functions.

## Why Verifiable Data Analytics

Without a proof, anyone who wants to check a published statistic must either rerun the
computation on the same data, which requires access to it, or trust the analyst. With a
zk-SNARK, the analyst produces a proof that the published result follows from the
computation, and the verifier checks the proof without seeing the private inputs.

## Arrays

### Static Arrays

A static array has a shape known at compile time. Inputs declare it in the annotation:

```python
from zinnia import *

@zk_circuit
def column_means(data: NDArray[Float, 100, 3]) -> NDArray[Float, 3]:
    return np.mean(data, axis=0)
```

`Float[Array, "100 3"]` is an equivalent spelling of the annotation. Static arrays are the
common case and give the smallest circuits.

### Runtime-Shaped Arrays

Some arrays have a shape that is only known when the proof is generated. Selecting the
elements that satisfy a condition on private data is the typical example. Zinnia represents
such an array as a *bounded-dynamic array*: a buffer whose size is a compile-time upper bound,
together with a runtime shape that the circuit checks against that bound. The circuit size
depends only on the bound.

```python
@zk_circuit
def sum_above(data: NDArray[Float, 100], threshold: Float) -> Float:
    selected = data[data > threshold]   # length known only at proving time
    return np.sum(selected)
```

Inputs can also have a runtime shape, for example `Float[DynArray, "N<=1024"]`. See
[Bounded-Dynamic Arrays](/docs/data-analytics/bounded-dynamic-arrays).

### Array Operations

Indexing, slicing, element-wise arithmetic with broadcasting, reductions, sorting, matrix
products and many other NumPy functions are supported. See
[Array Operations](/docs/data-analytics/array-operations).

## Real-Valued Arithmetic

The field holds integers modulo a prime. Zinnia represents a `Float` as a fixed-point number
with 32 fractional bits (Q32): the real number `x` is stored as the integer
`round(x * 2^32)`. Multiplication and division rescale their results, and values must stay in
the range the encoding supports. See
[Real-Valued Arithmetic](/docs/data-analytics/real-arithmetic).

## Non-Linear Functions

`exp`, `log`, `sqrt`, the trigonometric and hyperbolic functions and `arctan2` are computed
by fixed-point algorithms, typically a range reduction followed by a polynomial. The mock
backend evaluates the same algorithms that the halo2-base and Noir backends constrain. See
[Non-Linear Functions](/docs/data-analytics/nonlinear-functions).
