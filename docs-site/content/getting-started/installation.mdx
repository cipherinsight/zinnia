# Installation

Zinnia is a Python package with a native extension written in Rust. It is built from source with [maturin](https://www.maturin.rs/).

## Prerequisites

- **Python 3.10 or later.**
- **A Rust toolchain** (`cargo` and `rustc`), for example installed with [rustup](https://rustup.rs/).
- **For the Noir backend only:** the Noir toolchain `nargo` and the Barretenberg prover `bb`. Zinnia looks for them in the `ZINNIA_NARGO_BIN` and `ZINNIA_BB_BIN` environment variables, then at `~/.nargo/bin/nargo` and `~/.bb/bb`, then on `PATH`.

## Building from Source

Clone the repository, create a virtual environment and install the Python dependencies (NumPy, the Z3 solver and the test tools listed in `requirements.txt`) and maturin:

```bash
git clone <repository-url> zinnia
cd zinnia
python -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
python -m pip install -r requirements.txt
python -m pip install "maturin>=1,<2"
```

Then build the extension and install it into the virtual environment in editable mode:

```bash
PYTHON=.venv/bin/python scripts/develop.sh
```

`scripts/develop.sh` runs `maturin develop` and passes its arguments through. The Rust core links against Z3, and the script finds `libz3` in the `z3-solver` wheel, so no system Z3 installation is needed. It also sets the PyO3 compatibility flag that Python 3.14 needs.

## Proving Backends

The default build contains only the **mock** backend, which checks that the inputs satisfy the circuit without producing a proof. The backends that produce real proofs are optional Cargo features:

| Feature | Backend name | What it does |
|---|---|---|
| `halo2-base-backend` | `"halo2-base"` | Synthesizes and proves the circuit in-process with halo2-base (Halo2-lib). |
| `noir-backend` | `"noir"` | Emits a Noir program and proves it with `nargo` and `bb`. |

To build with both, use an optimized build with the features enabled. The halo2-base dependency uses an unstable Rust feature, so it needs `RUSTC_BOOTSTRAP=1` on a stable toolchain:

```bash
RUSTC_BOOTSTRAP=1 PYTHON=.venv/bin/python scripts/develop.sh --release --features halo2-base-backend,noir-backend
```

Selecting a backend that was not compiled in is an error. See [Execution](/docs/programming-guide/execution) for how to prove and verify.

## Verifying the Installation

Run one of the examples. It compiles a circuit and checks it on the mock backend:

```bash
python examples/fibonacci.py
```

The script finishes without output when the circuit is satisfied. To run the test suite:

```bash
python -m pytest
```
