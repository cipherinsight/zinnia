# Syntax Reference

Zinnia programs are syntactically valid Python. This page lists the statements and
expressions the Zinnia compiler accepts inside a circuit or a chip. Anything not listed
here (for example `try`, `with`, `class`, dictionary and set literals) is rejected with a
compile error.

## Circuits

A circuit is a function decorated with `@zk_circuit` (or passed to `ZKCircuit.from_method`
or `ZKCircuit.from_source`). Every parameter must carry a type annotation, which declares
an input of the circuit. The name `main` is reserved and cannot be used for a circuit.

```python
from zinnia import zk_circuit, Public, Private, Integer

@zk_circuit
def add_inputs(x: Public[Integer], y: Private[Integer]) -> Integer:
    result = x + y
    return result
```

## Statements

### Sequential Composition

Statements execute in order, top to bottom, within a block.

```python
a = 1
b = 2
c = a + b
```

### If / Elif / Else

```python
if x > 0:
    sign = 1
elif x == 0:
    sign = 0
else:
    sign = -1
```

### While Loops

A `while` loop is unrolled at compile time. The compiler must be able to prove that the
condition becomes false within a bounded number of iterations (see
[Control Flow](/docs/language/control-flow)).

```python
i = 0
total = 0
while i < 10:
    total = total + i
    i = i + 1
```

### For Loops

`for` loops iterate over `range(...)`, lists, tuples, arrays and iterator builtins such as
`enumerate`, `zip` and `reversed`.

```python
total = 0
for i in range(10):
    total = total + i
```

```python
values = [1, 2, 3, 4, 5]
total = 0
for v in values:
    total = total + v
```

Both `for` and `while` accept an `else` block.

### Break and Continue

```python
total = 0
for i in range(100):
    if i > 10:
        break
    if i % 2 == 0:
        continue
    total = total + i
```

### Helper Functions

A function called from a circuit is either a chip, decorated with `@zk_chip` and inlined at
each call, or an external function, decorated with `@zk_external` and run in Python outside
the circuit (see [Chips](/docs/programming-guide/chips) and
[External Functions](/docs/programming-guide/external-functions)).

```python
from zinnia import zk_chip, Integer

@zk_chip
def add(a: Integer, b: Integer) -> Integer:
    return a + b
```

A circuit may also define functions and lambdas in its body. The compiler turns each of
them into a chip; a local function that reads variables of the circuit receives them as
extra arguments.

```python
@zk_circuit
def scaled_sum(xs: NDArray[Integer, 4], k: Integer) -> Integer:
    def scale(v):
        return v * k
    return sum(scale(v) for v in xs)
```

### Input Declarations

Circuit parameters declare the inputs. `Public[T]` marks a public input, `Private[T]` a
private one, and a parameter annotated with a bare type `T` is private.

```python
@zk_circuit
def check(x: Public[Integer], witness: Private[NDArray[Float, 3, 3]]):
    assert x > 0
```

### Assignments

```python
x = 42
label = "hello"
matrix = np.zeros((3, 3))
```

An annotated assignment such as `x: Integer = 42` is accepted. The annotation is ignored
because types are inferred. A bare annotation without a value (`x: Integer`) is rejected.

### Augmented Assignment

```python
x += 1
y -= 2
z *= 3
w /= 4
r %= 5
p **= 2
q //= 3
m &= 1
```

All binary operators listed under [Binary Operators](#binary-operators) have an augmented
form. On an array or list, the update is made in place, as in Python.

### Return Statements

```python
@zk_chip
def square(x: Integer) -> Integer:
    return x * x
```

### Assert Statements

An assertion compiles to a circuit constraint. If the condition is false for the given
inputs, no valid proof exists. The optional message is ignored by the compiler.

```python
assert x >= 0
assert balance == expected, "balance mismatch"
```

### Raise Statements

A `raise` statement compiles to `assert False` on the path that reaches it.

```python
if x < 0:
    raise ValueError("x must be non-negative")
```

### Imports

`import numpy as np`, `import math` and imports from their submodules are accepted inside
a circuit and resolved at compile time. Importing any other module is a compile error.

### Pass Statements

```python
if flag:
    pass
```

## Expressions

### Literals

Integer, float, complex, boolean, string and `None` literals are accepted. Strings serve as
labels (for example in `print` or assertion messages) and f-strings are accepted for the
same purpose.

```python
a = 42          # integer
b = 3.14        # float
c = 1 + 2j      # complex
d = True        # boolean
e = "hello"     # string
f = None        # None
```

### Binary Operators

```python
# Arithmetic
a = x + y
b = x - y
c = x * y
d = x / y       # true division: always a float
e = x % y
f = x ** 2
g = x // y

# Matrix multiplication
h = A @ B

# Bitwise (integers and booleans)
i = x & y
j = x | y
k = x ^ y
l = x << 2
m = x >> 2

# Logical
p = a and b
q = a or b
```

### Comparisons

`==`, `!=`, `<`, `<=`, `>`, `>=`, `in` and `not in` are accepted. Chained comparisons such
as `lo <= x < hi` are evaluated as a conjunction. `is` and `is not` are rejected because
circuit values have no object identity.

### Unary Operators

```python
a = -x
b = +x
c = not flag
d = ~mask
```

### Indexing and Slicing

```python
val = arr[0]           # single element
val = matrix[i, j]     # multi-dimensional
sub = arr[1:5]         # slice
sub = arr[0:10:2]      # slice with step
sub = arr[::-1]        # reversed
col = matrix[:, 0]     # first column
```

Indices may be runtime values, and arrays also accept integer-array and boolean-mask
indices (see [Arrays](/docs/language/arrays)).

### List and Tuple Construction

```python
xs = [1, 2, 3, 4, 5]
empty = []
nested = [[1, 2], [3, 4]]
pair = (1, 2)
single = (42,)
```

### Function Calls

```python
result = add(3, 4)          # a chip
length = len(my_list)
total = sum(values)
s = math.sin(theta)
arr = np.zeros((3, 3))
```

Positional, keyword and starred (`f(*args)`) arguments are accepted.

### Conditional Expressions

```python
result = a if condition else b
```

### Comprehensions and Generator Expressions

List comprehensions and generator expressions are accepted, including `if` filters and
several `for` clauses.

```python
squares = [x * x for x in values]
total = sum(x * x for x in values)
has_positive = any(v > 0 for v in data)
```

### Attribute Access

Attributes give access to module functions, array properties and methods.

```python
s = arr.shape
t = arr.T
n = arr.ndim
r = math.sqrt(2.0)
```

## Assignment Targets

```python
x = 10                     # name
arr[0] = 99                # subscript
matrix[i, j] = 1.0
[a, b, c] = [1, 2, 3]      # list unpacking
a, b = 1, 2                # tuple unpacking
first, *rest = values      # starred unpacking
```

## Comments

Comments are ignored by the compiler.

```python
# This is a comment
x = 42  # inline comment
```
