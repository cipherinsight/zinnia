# Privacy Annotations

The type annotation of a circuit parameter says whether the input is public (known to the
prover and the verifier) or private (known only to the prover). Public inputs and the
circuit's outputs form the public values of the proof. Private inputs are part of the
witness and are not revealed by the proof.

## Public and Private

### Public[T]

`Public[T]` declares a public input of type `T`. Anyone verifying the proof sees its
value.

```python
@zk_circuit
def nonnegative(balance: Public[Integer]):
    assert balance >= 0
```

### Private[T]

`Private[T]` declares a private input of type `T`. The prover supplies it when the proof
is generated, and the verifier does not learn it. A parameter annotated with a bare type
`T` is private as well.

```python
@zk_circuit
def knows_root(square: Public[Integer], root: Private[Integer]):
    assert root * root == square
```

### Combined Usage

```python
@zk_circuit
def verify_balance(
    public_balance: Public[Integer],
    accounts: Private[NDArray[Integer, 10]],
):
    assert accounts.sum() == public_balance
```

The verifier learns the total balance but not the individual account entries.

## Supported Input Types

`Public` and `Private` can wrap any input type: scalars, arrays, bounded-dynamic arrays,
lists, tuples and `PoseidonHashed` values.

```python
@zk_circuit
def inputs(
    a: Public[Integer],
    b: Private[Float],
    c: Public[Bool],
    m: Public[NDArray[Integer, 3, 3]],
    v: Private[NDArray[Float, 10]],
    d: Private[DynamicNDArray[Integer, 100, 1]],
    t: Private[Tuple[Integer, Float]],
):
    pass
```

Every input element is checked to lie in the domain of its type: integers in the `int64`
range, floats in the fixed-point range, and Booleans equal to 0 or 1. An input that the
circuit never reads after optimization is not part of the proven statement.

## Outputs

The return value of a circuit is a public output. Each element of a returned scalar, array,
list or tuple becomes a public value of the proof, except elements whose value the
compiler knows at compile time, which are left out of the public values. A circuit that
returns nothing has as outputs the array arguments it writes into, with their final
contents.

```python
@zk_circuit
def private_mean(data: Private[NDArray[Float, 100]]) -> Float:
    return data.sum() / 100.0
```

Here the verifier learns the mean of 100 private values and nothing else about them.

### Layout of the Public Values

Each public input occupies one public value per element (an `NDArray[Integer, 3, 4]` input
occupies 12), and so does each output element. A `DynamicNDArray` output also exposes its
runtime length and shape. The compiled program describes where each value is:

```python
program = ZKCircuit.from_method(private_mean).compile()
program.get_public_inputs()    # public inputs and their positions
program.get_output_layout()    # outputs and their positions or constant values
program.describe_publics()     # what each public value is, by position
```

## PoseidonHashed

`PoseidonHashed[T]` is an input of type `T` that comes with its Poseidon hash. Poseidon is
a hash function designed to be cheap inside arithmetic circuits. The circuit reads both the
value and the hash, computes the Poseidon hash of the value's elements, and asserts that
the two hashes are equal. Inside the circuit, the parameter holds the value itself.

```python
from zinnia import zk_circuit, PoseidonHashed, NDArray, Integer

@zk_circuit
def committed_sum(x: PoseidonHashed[NDArray[Integer, 2, 2]]):
    assert x.sum() == 10

committed_sum(PoseidonHashed([[1, 2], [3, 4]], 0))
```

The argument is a `PoseidonHashed(value, hash)` object or the plain value. In both cases
the hash placed in the witness is computed from the value when the inputs are built, so the
second argument of `PoseidonHashed` is not used. `PoseidonHashed` can also appear inside
other types, for example `Tuple[PoseidonHashed[Integer], Integer]`.

A `Public` or `Private` annotation on a `PoseidonHashed` input applies to both the value
and its hash.

Hashing is supported by the `mock` and `halo2-base` backends. The `noir` backend rejects
circuits that contain a Poseidon hash.

## Design Patterns

### Proving a Property of Private Data

```python
@zk_circuit
def all_in_range(data: Private[NDArray[Integer, 50]], lo: Public[Integer], hi: Public[Integer]):
    for v in data:
        assert lo <= v
        assert v <= hi
```

The prover shows that every private value lies in a public interval without revealing the
values.

### Selective Disclosure

```python
@zk_circuit
def selected_sum(
    values: Private[NDArray[Integer, 10]],
    mask: Private[NDArray[Bool, 10]],
) -> Integer:
    total = 0
    for i in range(10):
        if mask[i]:
            total = total + values[i]
    return total
```

The prover reveals the sum of a selected subset of the private values without revealing
which values were selected or what the individual values are.
