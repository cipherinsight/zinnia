# Operators and Built-in Functions

This page lists the operators and built-in functions available inside a circuit. NumPy
functions are listed on the [NumPy API](/docs/programming-guide/numpy-api) page.

## Arithmetic Operators

| Operator | Description         | Operands                         |
|----------|---------------------|----------------------------------|
| `+`      | Addition            | numbers, arrays                  |
| `-`      | Subtraction         | numbers, arrays                  |
| `*`      | Multiplication      | numbers, arrays                  |
| `/`      | True division       | numbers, arrays (result is float)|
| `//`     | Floor division      | numbers, arrays                  |
| `%`      | Modulo              | numbers, arrays                  |
| `**`     | Exponentiation      | numbers, arrays                  |
| `@`      | Matrix multiply     | arrays                           |

```python
a = 10 + 3      # 13
b = 10 - 3      # 7
c = 10 * 3      # 30
d = 10 / 4      # 2.5 (true division always gives a float)
e = 10 // 3     # 3
f = 10 % 3      # 1
g = 2 ** 10     # 1024

A = np.asarray([[1, 2], [3, 4]])
B = np.asarray([[5, 6], [7, 8]])
C = A @ B       # [[19, 22], [43, 50]]
```

Arithmetic between an integer and a float gives a float, and arithmetic involving a complex
number gives a complex number. On lists and tuples, `+` concatenates and `*` repeats, as in
Python.

## Bitwise Operators

`&`, `|`, `^`, `<<`, `>>` and `~` apply to integers and Booleans. On Booleans, `&`, `|` and
`^` are the logical connectives. Shifts follow NumPy's `int64` shifts.

## Comparison Operators

| Operator | Description              |
|----------|--------------------------|
| `==`     | Equal                    |
| `!=`     | Not equal                |
| `<`      | Less than                |
| `<=`     | Less than or equal       |
| `>`      | Greater than             |
| `>=`     | Greater than or equal    |
| `in`     | Membership in a list, tuple or array |
| `not in` | Negated membership       |

Comparisons return Booleans. On arrays they apply element-wise and return a Boolean array.
Ordering comparisons need range checks in the circuit, so they cost more constraints than
equality.

```python
is_positive = x > 0
in_range = lo <= x <= hi
```

## Logical Operators

| Operator | Description       |
|----------|-------------------|
| `and`    | Logical AND       |
| `or`     | Logical OR        |
| `not`    | Logical NOT       |

```python
valid = x > 0 and y > 0
negated = not flag
```

## Unary Operators

| Operator | Description       |
|----------|-------------------|
| `+x`     | Unary plus        |
| `-x`     | Negation          |
| `~x`     | Bitwise inversion |

## Built-in Functions

### General

| Function       | Description                                       |
|----------------|---------------------------------------------------|
| `len(x)`       | Length of a list, tuple or array                  |
| `range(...)`   | Integer range for iteration                       |
| `enumerate(x)` | Pairs of index and element                        |
| `zip(...)`     | Elements of several sequences taken together      |
| `sum(x)`       | Sum of elements                                   |
| `any(x)`       | True if any element is true                       |
| `all(x)`       | True if all elements are true                     |
| `min(...)`     | Minimum of the arguments or of a sequence         |
| `max(...)`     | Maximum of the arguments or of a sequence         |
| `abs(x)`       | Absolute value                                    |
| `pow(x, y)`    | Exponentiation (same as `x ** y`)                 |
| `print(...)`   | Debug output when the circuit is evaluated        |

```python
n = len([1, 2, 3])          # 3
total = sum([1, 2, 3, 4])   # 10
has_neg = any(v < 0 for v in data)
lo = min(3, 7)              # 3
a = abs(-5)                 # 5
p = pow(2, 10)              # 1024
```

`map` and `filter` with a function argument are also accepted and are compiled as
generator expressions.

### Type Conversion

| Function     | Description            |
|--------------|------------------------|
| `int(x)`     | Convert to integer     |
| `float(x)`   | Convert to float       |
| `bool(x)`    | Convert to Boolean     |
| `complex(x)` | Convert to complex     |
| `list(x)`    | Convert to list        |
| `tuple(x)`   | Convert to tuple       |

```python
i = int(3.7)        # 3
f = float(42)       # 42.0
b = bool(1)         # True
```

## Math Module

`math` functions apply to scalars. The following are available:

| Function or constant | Description              |
|----------------------|--------------------------|
| `math.sqrt(x)`       | Square root              |
| `math.exp(x)`        | Exponential              |
| `math.log(x)`        | Natural logarithm        |
| `math.sin(x)`, `math.cos(x)`, `math.tan(x)` | Trigonometric functions |
| `math.sinh(x)`, `math.cosh(x)`, `math.tanh(x)` | Hyperbolic functions |
| `math.asin(x)`, `math.acos(x)` | Inverse sine and cosine |
| `math.atan2(y, x)`   | Two-argument arctangent  |
| `math.fabs(x)`       | Absolute value as a float |
| `math.pow(x, y)`     | Power                    |
| `math.pi`, `math.e`  | Constants                |

```python
import math

y = math.sin(math.pi / 2)    # approximately 1.0
r = math.sqrt(2.0)           # approximately 1.414
```

The transcendental functions are computed in fixed point and are approximations. See
[Nonlinear Functions](/docs/data-analytics/nonlinear-functions).

## List Methods

| Method              | Description                                 |
|---------------------|---------------------------------------------|
| `list.append(x)`    | Add an element to the end                   |
| `list.extend(xs)`   | Append the elements of a sequence           |
| `list.insert(i, x)` | Insert an element at position i             |
| `list.pop(i=-1)`    | Remove and return the element at position i |
| `list.copy()`       | Return a shallow copy                       |
| `list.clear()`      | Remove all elements                         |
| `list.reverse()`    | Reverse the list in place                   |
| `list.index(x)`     | Index of the first occurrence of x          |
| `list.count(x)`     | Number of occurrences of x                  |
| `list.remove(x)`    | Remove the first occurrence of x            |

```python
xs = [1, 2, 3]
xs.append(4)          # [1, 2, 3, 4]
xs.extend([5, 6])     # [1, 2, 3, 4, 5, 6]
xs.insert(0, 0)       # [0, 1, 2, 3, 4, 5, 6]
last = xs.pop()       # 6, xs = [0, 1, 2, 3, 4, 5]
idx = xs.index(3)     # 3
xs.reverse()          # [5, 4, 3, 2, 1, 0]
```

| Method or property        | Description                                |
|---------------------------|--------------------------------------------|
| `arr.sum(axis=None)`      | Sum of elements                            |

| `arr.argmax(axis=None)`   | Index of the maximum element               |
| `arr.argmin(axis=None)`   | Index of the minimum element               |
| `arr.all(axis=None)`      | True if all elements are true              |
| `arr.any(axis=None)`      | True if any element is true                |
| `arr.mean(axis=None)`     | Mean of elements                           |
| `arr.cumsum()`, `arr.cumprod()` | Cumulative sum and product           |
| `arr.clip(lo, hi)`        | Limit values to an interval                |
| `arr.nonzero()`           | Indices of non-zero elements               |
| `arr.transpose()`, `arr.T`| Transpose                                  |
| `arr.moveaxis(src, dst)`  | Move an axis                               |
| `arr.swapaxes(a, b)`      | Swap two axes                              |
| `arr.reshape(shape)`      | Reshape                                    |
| `arr.flatten()`, `arr.ravel()` | Flatten to 1-D                        |
| `arr.squeeze()`           | Remove dimensions of size 1                |

| `arr.astype(dtype)`       | Convert the element type                   |

| `arr.copy()`              | Copy                                       |
| `arr.filter(mask)`        | Elements where `mask` is true, as a `DynamicNDArray` |
| `arr.real`, `arr.imag`, `arr.conjugate()` | Complex parts and conjugate |

```python
mat = np.asarray([[3, 1], [4, 1]])

s = mat.sum()              # 9

r = mat.reshape((1, 4))    # [[3, 1, 4, 1]]
```

## Numbers in the Circuit

All values are represented by elements of the backend's prime field (the BN254 scalar
field for `halo2-base` and `noir`). This has the following consequences:

- **Integers.** Integer inputs are constrained to NumPy's `int64` range.
- **Floats.** Floats are fixed-point numbers with 32 fractional bits, so their resolution
  is `2^-32` (about `2.3e-10`), and float inputs lie in `[-2^31, 2^31)`.
- **Comparisons.** Ordering comparisons need range checks, which add constraints.
